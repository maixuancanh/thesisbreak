# UI V6

Live detail now places Your view before collapsed resolution rules and source details. The form requires an explicit outcome, allows an optional reason up to 4000 characters, checks account status, then shows a review before posting to the account API. A request UUID is persisted before POST and reused for identical retries across reload; changed payloads receive a new UUID. Strict session receipts are scoped to the authenticated user ID, market, and provider. Saved receipts suppress duplicate saves after reload. Account identity is checked again before posting; a changed account must review again. Without a stable authenticated user ID, receipts are not restored across sessions. Success links to My picks. Errors retain the draft and point to Account when appropriate.

My picks loads actual account records from GET /api/picks. Fictional local preview picks are available only through the explicit Sample scenarios disclosure; nothing imports them into the account. Sample detail routes show Sample scenario, Fictional event, and Browse live markets near the heading.

Drafts use strict validated sessionStorage records partitioned by platform, native ID, and resolved provider. They remain in the current browser tab; account storage still requires a successful server response. Discovery keeps platform choices visible and places transport choices inside Data connection. Event titles render only when supplied by the source. Dates use the viewer locale and timezone, including timezone detail.

The Thesis pane stays mounted when switching Market / Thesis on mobile. Starter prompts populate the composer without generating responses. Send remains visible and disabled with the unconfigured explanation. No agent replies or changes are simulated. Existing shadcn Button components and the current font/color identity are retained; no dependencies added.

Verification: pure helper tests cover payload identity, source preservation, stable retries, strict drafts, and date labels. The implementation run passed typecheck, production build, ESLint, and 9 targeted unit tests. A final scroll-position preservation edit was typechecked and linted after that build. Browser interaction is disabled in Work settings, so authenticated saving, mobile keyboard/focus, responsive layout, and visual usability remain unverified. No deployment or usability study is claimed.
